# Город 24 — конструктор постов

Собирает обложки и карусели для Instagram по макетам «Город 24» из Figma:
выбираешь рубрику, пишешь текст, добавляешь фото — шрифты, отступы,
тени, сетка и логотип уже на месте. Работает целиком в браузере, фото
никуда не отправляются. Один файл `index.html`, внутри всё: шрифты,
логотип, картинки. Сделан по образцу Card Maker (`card-maker-wemedia`),
но в первую очередь — для телефона.

---

## Ссылка

**https://ehroz1.github.io/gorod24/** — открывается на любом телефоне и
компьютере, ставить ничего не нужно. Сайт публикуется GitHub Pages из
ветки `gh-pages` (Settings → Pages).

Если менял код в `src/` или файлы в `brand/` — пересобери (см. ниже),
закоммить и отправь в `gh-pages`: обновятся три файла из корня
(`index.html`, `manifest.webmanifest`, `service-worker.js`), сайт
обновится сам за минуту.

---

## Шрифты и логотип

Всё уже вшито: **BravoRG** (заголовки), **Nauryz Red Keds** (рубрики
«Заведения» и «Новые места»), **Inter** (текст) и векторный логотип
«город 24». Коллегам ничего устанавливать не нужно.

Заменить шрифт или логотип: положи новый файл в `brand/` (имена — в
`brand/ПОЛОЖИ_СЮДА_ФАЙЛЫ.txt`), запусти `python3 build.py` и залей три
собранных файла. Быстрый способ только для своего браузера — редактор →
вкладка **Настройки** → «Шрифты и логотип».

## Как пользоваться

### Стартовый экран

- **Продолжить** — черновики с превью обложки. Всё сохраняется само:
  тексты и **фото тоже** (в памяти браузера), так что можно уйти в «Фото»
  или закрыть вкладку и вернуться. Крестик на карточке удаляет черновик.
- **Новый пост** — девять рубрик из макета. Нажал — открылась обложка и
  пара карточек.

| Рубрика | Слайды |
|---|---|
| Заведения | обложка «Заведения Душанбе» + карточки заведений |
| Интервью | обложка + карточки «01. Вопрос» / ответ (белые, с сеткой); на карточку можно добавить ещё до трёх блоков «заголовок + текст» |
| Любимые места | обложка со стрелкой + карточки со стопкой фотографий |
| Новые места | обложка + карточка: название, 📍 адрес, описание в белой плашке |
| Мероприятия | обложка «11 мероприятий недели» + карточка-полароид со скрепкой: название, 🗓️ дата и время, 📍 место, 💵 цена — каждую строку можно выключить |
| Киноафиша | обложка с логотипом по центру + карточка фильма: название, плашка «Премьера: …», описание |
| Коммерция | обложка + карточки с фото сверху или снизу |
| Пост | одна картинка с крупным заголовком |
| Рилс | обложка 1080×1920 |

Любой макет можно добавить в любой проект: «+ Слайд» в ленте.

### Редактор на телефоне

Сверху превью слайда, под ним лента миниатюр, ниже — поля.

- **Текст** пишется в полях, превью меняется сразу. Бледный текст на
  слайде — подсказка, в картинку он не попадёт. Пока печатаешь, превью
  уменьшается и остаётся над клавиатурой.
- **Фото или видео** — кнопка прямо на превью или в блоке «Фото».
  Можно выбрать сразу несколько: разложатся по слайдам, для лишних
  добавятся новые карточки. Кадр двигается пальцем прямо на превью,
  щипок — масштаб. Подходят JPEG, PNG, WebP и **HEIC** (фото с iPhone):
  Safari открывает HEIC сам, а в Chrome, Firefox и Edge при первом таком
  фото подгружается декодер (~3 МБ, один раз — дальше он в кеше). В
  проект HEIC ложится уже как JPEG.
- **Видео** встаёт в любой макет вместо фото (обложка, стопка фото,
  полароид, фото сверху/снизу). Ползунки «Начало» и «Конец» задают
  фрагмент, «▶» на превью проигрывает его прямо в макете. На миниатюре
  видео-слайда — значок плёнки.
- **Листать** — свайп по превью, стрелки по бокам или лента.
- **Ещё раз нажать на текущий слайд в ленте** — меню: сменить макет,
  дублировать, переставить, удалить.
- **Глаз** вверху — просмотр всей карусели как в Instagram, свайпом.
- **Сохранить** → «Сохранить в Фото / отправить»: откроется системное окно,
  там «Сохранить изображения» (попадут в Фото) или сразу Instagram/Telegram.

### На компьютере

Три колонки: слайды (перетаскиваются мышью), превью, поля. Фото можно
перетащить на превью или миниатюру, вставить через ⌘V. Колесо мыши над
фото — масштаб.

Горячие клавиши: ⌘Z / ⌘⇧Z — отменить/повторить, ⌘S — сохранить,
⌘V — вставить фото, PageUp/PageDown или ←/→ — соседний слайд, Esc —
закрыть окно. На Windows вместо ⌘ — Ctrl.

### Если текст не помещается

Под превью появится «Текст не помещается» и жёлтая точка на миниатюре.
«Уместить» уменьшит кегль, пока текст не влезет (не меньше 60% от
макета), или подвинь ползунки «Размер текста». «Как в макете» вернёт.

### Оформление

- **Стрелка «листай»** — там, где она есть в макете (включается и
  выключается).
- **Затемнение** — «тень» снизу под текстом на обложках, 0–100%.
- **Фирменный цвет** — перекрашивает слайд в кремовый **#FEF3BD**: на
  слайдах с фото — текст, стрелку и плашки (белая плашка «Новых мест»,
  «Премьера» в киноафише), на белых карточках — фон (текст остаётся
  тёмным). Логотип не меняется. Кнопкой под переключателем можно сделать
  так же на всех слайдах проекта.
- **Макет** — сменить макет слайда, текст сохранится.
- **Ещё заголовок и текст** (карточка «Интервью») — кнопка под полями
  добавляет на ту же карточку ещё один блок «заголовок + ответ», всего до
  четырёх. Блоки идут друг под другом; крестик у блока убирает его,
  следующие подтягиваются.
- **Необязательные строки** (дата, место, цена, адрес, плашка) — у каждой
  переключатель рядом с подписью: выключенная строка пропадает со слайда,
  остальные подтягиваются, а набранный текст сохраняется до включения.

### Экспорт

PNG или JPG, **1440×1800** (как в макете) или **1080×1350**; рилс —
1080×1920.

Слайды с видео сохраняются роликом **MP4 1080 px со звуком** (Chrome,
Edge, Safari; Firefox умеет только WEBM, а его Instagram не принимает).
Ролик записывается в реальном времени — 15-секундный фрагмент пишется
15 секунд, вкладку в это время не сворачивать. В карусели Instagram видео
до 60 с, в рилс — до 90 с: длиннее конструктор предупредит. Все слайды одним ZIP, по одному или только текущий; на
компьютере ещё «Скопировать слайд в буфер». Пустые слайды не
сохраняются. Файлы называются латиницей по названию проекта
(`kofeynya-zerno-01.png`) — название само повторяет заголовок обложки,
пока его не поменяли вручную (Настройки → Проект).

### Черновики на другом устройстве

Настройки → «Сохранить файл» — тексты и настройки без фото. На другом
устройстве: стартовый экран → «Открыть проект из файла».

### Установить как приложение

Safari: «Поделиться» → «На экран «Домой»». Chrome/Android: баннер
«Установить» или меню → «Установить приложение». После первого открытия
работает без интернета.

## Сборка

Приложение, которое открывают, — это собранный `index.html`, а не файлы в
`src/`. После любых правок в `src/` или `brand/`:

```bash
pip3 install fonttools brotli   # один раз: шрифты урежутся и файл станет меньше
python3 build.py
```

Проверить локально (с диска `file://` не работают установка и офлайн):

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Структура

```
index.html              готовое приложение (собирается)
manifest.webmanifest    для установки как приложение (собирается)
service-worker.js       офлайн-кеш страницы (собирается)
build.py                сборка трёх файлов выше
src/
  render.js             отрисовка слайдов — ВСЕ размеры макетов здесь (LAYOUTS)
  app.js                интерфейс: рубрики, черновики, фото, жесты, экспорт
  styles.css            оформление интерфейса (не слайдов)
  index.template.html   каркас страницы
  manifest.template.json, service-worker.js
vendor/
  heic-to.js            декодер HEIC (libheif), грузится только при открытии HEIC
brand/
  logo.svg              логотип — белый знак (вектор)
  photo-stack.png       стопка фотографий из «Любимых мест»
  pwa-icon.svg, pwa-icon-180.png   значок приложения
  fonts/                title.otf (BravoRG), display.ttf (Nauryz Red Keds),
                        body.ttf, body-italic.ttf (Inter), fallback-*.ttf (запасные)
  icons/                иконки интерфейса — Phosphor Icons (Bold), MIT
```

Лицензии шрифтов — `brand/fonts/LICENSE.txt`, иконки Phosphor — MIT
(`brand/icons/LICENSE`), декодер HEIC [heic-to](https://github.com/hoppergee/heic-to) —
LGPL-3.0 (`vendor/heic-to.LICENSE.txt`, как обновить — `vendor/README.md`).
